## 修复

1. 弹窗错误现在显示在弹窗内，失败后保留输入；重新打开时清除旧错误。
2. 弹窗增加标题、dialog 语义、背景 inert、初始焦点、Tab / Shift+Tab 循环和 Esc；关闭后恢复触发位置，忙碌时阻止关闭。
3. 截图读取 / 校验失败不再永久显示“图片读取中”，可重新校验并加载；移除跨挂载的旧图片缓存。
4. 小高度日志页压缩重复留白与统计布局，保留更多事件列表空间。
5. 验收增加原生命令调用计数、真实内核测试、10 资产后台周期测试与导出物理文件检查；开发测试命令只允许隔离验收模式使用。

## 可复现入口

`cargo test --manifest-path src-tauri/Cargo.toml --offline`（使用本项目配置的 CARGO_TARGET_DIR）；`go test ./...` 和 `go vet ./...` 在 agent 目录运行。

`tests/native-platform.mjs` 使用实际 .app 可执行文件和独立数据库，包含后台调度约 75 秒等待；原生界面验收按单实例串行运行。`tests/native-http.mjs` 为独立 HTTP 复测；`tests/native-field-ui.mjs` 读取已完成容器 / 大日志验证的工作区。`tests/check-artifacts.py` 检查文件，需要 Pillow，可安装在独立测试 venv。

开发二进制的 `--verify-field` 与 `--verify-ebpf` 必须指定新隔离目录及 Agent 模板。前者使用带 manifest 的禁用 PHP / 无害脚本与已存在的 Docker 镜像；本轮使用 `php:7.4-apache`，仅容器临时目录可写；后者只观察一次性容器自己的回环网络。`--verify-official` 只读取指定工作区的配置元数据，Key 保留在系统凭据服务，只发送固定合成材料。

既有 C4 文档位于源码 `docs/C4-architecture-0.6.0.md`，核心层次不变；本轮新增通用 Modal 和开发验收工具。当前软件不是已完成的全自动取证 / 溯源产品；上述缺口均保留为明确待办。
