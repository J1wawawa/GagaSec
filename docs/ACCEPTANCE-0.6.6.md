## 实际范围

四个只读工具：元信息、脚本行片段、ASCII 字符串、x86 / x64 PE / ELF 入口附近线性反汇编。容器禁网 / 只读根 / 非 root / 无宿主机挂载；启动前 inspect 校验，完成、取消及失败时清理。

反分析检查只识别固定 ASCII 字符串，保存行号 / 文件偏移，注释命中也只算候选；无动态逃逸验证。不包含反编译、自动脱壳、多环境自动执行、来宾外监控、内存取证或真实恶意样本检出率保证。动态行为页显式提示未观察到行为不能说明安全。

报告为实际导出的 HTML / DOCX。PDF 仍通过系统打印，不将浏览器导出代替原生打印验收。模型、工具工件、原始材料与调查节点分别保存；完整样本 Hash 由程序写入，不依赖模型是否缩写。
