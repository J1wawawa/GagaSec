# 0.7.0 本机验收

2026-10-28，面向防御团队、运行在个人 PC 上的一站式安全终端。交付为 macOS arm64、ad-hoc 签名的开发预览版；不是零缺陷承诺。所有测试使用独立临时工作区、合成材料或固定无害诊断，不执行真实木马，不修改客户主机。

## 本版交付

- 总览提供可收起并记忆的五步调查指引；报告保持顶部独立入口。
- 设置增加“数据与维护”和统一功能/平台验证清单。备份、校验恢复、下次启动切换、存储统计、脱敏诊断均已连接真实后端。
- SQLite 一致快照，证据/截图摘要校验，失败恢复目录清理；恢复后停用巡检、自动 AI 和旧采集任务，不复制系统凭据。
- 结构升级前保存数据库快照，成功才写结构版本，拒绝较新结构与失效启动指针。
- 采集 RSA-OAEP 私钥运算迁至 AWS-LC，保持旧 PKCS#8、label 与 Go 包兼容。移除受 RUSTSEC-2023-0071 影响的 RustCrypto rsa；HTTPS 接收默认关闭，显式配置后启动。
- 修正隔离 Worker 版本与锁文件不一致导致的 Docker 构建失败。错误保留日志末尾，限制错误框高度，避免遮住工作区。
- 提供公开合成 HTTP 规则评测、使用指南、C4 文档、安全政策、问题模板和发布流程。

## 存储与恢复

备份为含 manifest.json 的目录，不是 ZIP，不含系统凭据、Docker 镜像、可重建日志索引及 WebView 未确认草稿。备份期间后续修改属于下一次快照。报告存在待恢复草稿时界面阻止备份，要求先保存或恢复。

恢复限制单文件 2 GiB、总量 256 GiB 和文件/目录数量；拒绝链接、路径穿越、重复路径、缺失证据、摘要不符及带触发器/视图/虚拟表的数据库。manifest 不是数字签名，仅导入可信来源备份。恢复不覆盖当前工作区，激活仅影响下次启动。证据、截图、报告、备份和解密材料均为本机明文；没有完整证据库加密、团队认证或证据自动删除。

## 依赖与发布状态

两个 npm audit 均为 0。OSV 查询 554 条依赖/工具链记录，仍有 5 个 Rust 包匹配，详见 [依赖审阅](DEPENDENCY-REVIEW-0.7.0.md)；没有宣称供应链问题清零。AWS-LC 运算迁移不是整个协议通过独立密码学审计。

源码和客户端随附使用指南、许可和验证记录；原始任务 ZIP、私钥、Token、真实模型 Key、工作区数据库与客户材料不作为验收附件公开。固定公开测试私钥 fixtures/agent-interop/test-only-private.pem 仅供跨语言测试，生产不使用。

## 未完成的外部验收与能力

Windows 桌面/Agent 实机、真实 CAPE Windows VM、Qwen/GLM/Kimi 官方 Key、实际目标主机不同内核与权限、外部资产长期巡检、多事件长期容量、系统打印交互、外部首次用户观察和操作录屏仍待完成。CI 配置存在，尚无远端 CI 成功记录。

普通 Docker 共享内核，不是运行真实恶意样本的充分隔离环境。复杂混淆、脱壳、反调试、反沙箱和延迟触发只提供有限静态线索与覆盖说明，没有通用绕过或检出保证。Pi 提供四个受控只读工具，不自动反编译、不执行样本。微步/WHOIS/RDAP、完整 PCAP/TLS 明文还原、OpenCode、多用户协作、后台 PDF 渲染没有实现。
