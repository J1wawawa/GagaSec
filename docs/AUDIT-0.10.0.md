# 0.10.0 · 官方情报查询验收

日期：2026-10-30。平台：macOS / Apple Silicon。定位仍为个人 PC 上的一站式防御调查终端。本轮使用独立临时工作区，不读取客户材料，不读取或调用已有 AI Key，不运行恶意样本。

## 已实现

微步入站信誉、出站失陷线索、IP/域名上下文和已有文件报告；域名 RDAP；AbuseIPDB 30 天 IP 举报背景；VirusTotal 既有 Hash 报告。独立服务配置、系统凭据库、默认外发锁、明确指标确认、规范化去重、事件归属、有界后台任务、取消、缓存和来源快照已接入客户端。服务结果不覆盖人工 IOC 结论。

从分析结果指标或本地 IOC 带入，完成后经复核举证窗口保存负责人/截图/章节，再进入既有时间胶囊和报告导出。无样本上传、URL 主动扫描、样本下载、自动举报、清理或封禁接口。详见 [功能说明](THREAT-INTELLIGENCE-0.10.0.md)、[C4](C4-intelligence-0.10.0.md) 和 [接口](IPC-API.md)。

原生验收查询的是允许公开的 `icann.org`，通过 IANA bootstrap 找到注册服务并取得域名对象，核对返回域名、HTTPS 来源、取得时间和 SHA-256。只发生该公开 RDAP 查询；缓存、特殊域名和跨事件负例均在本地验证，不消耗鉴权服务额度。

20 项原生检查包括：默认锁及四家服务默认停用、设置厂商列表、RDAP 不索取 Key、未确认外发不能查询、确认后可查询、真实注册结果、源时间/摘要、列表不带大响应、来源限制说明、960×660 明暗两主题布局、可编辑举证窗口、当前事件节点与证据、真实 HTML 报告引用、缓存复用原时间、特殊域名未外发、第二事件独立、越事件读取拒绝、锁定后禁止查询、未触发 AI/样本执行或上传。

后端专项核对微步 HTTP 200 的负业务码、无数据/处理中/部分成功、出口 IP 未绑定、授权到期、配额和 HTTP 401/403/429/重定向；验证固定只读路由、Key 不进 URL、真实回环 HTTP 的错误正文丢弃/JSON 凭据脱敏/大响应拒绝、私网/特殊 IPv4/IPv6 阻止、缓存按事件/配置/参数隔离、取消后晚到响应不能覆盖、重启中断、结果摘要校验、幂等举证和保留本地人工判断。真实备份/恢复验证默认锁及服务授权重置。

## 本轮发现并修复

初次原生流程完成了 RDAP 查询，但未通过来源举证入口检查。检查发现既有平台隐藏样式使用 `!important`，新在线区未显式覆盖，已修复；同时加入完成事件刷新和点击同条记录重新读取详情，避免只依赖定时刷新。修复后新建独立工作区重新执行 20 项原生检查并通过，初次失败未计入通过结果。

数据与并发处理还包含：配置保存遇到系统凭据弹窗后重读外发锁；入队/锁定串行；响应只允许覆盖未终止任务；恢复备份清除情报配置；报告结果先校验规范化摘要；大结果不随列表反复传输；鉴权/额度问题停止本批后续请求；后台安全错误进入现有运行日志。

## 未覆盖与限制

没有微步、AbuseIPDB、VirusTotal 的可用授权账号，**未执行这三家的正式鉴权/配额/真实字段端到端验收**。固定路由、参数、解析和失败路径的合同测试不等于正式服务测试。系统凭据路径有实现，但本轮没有为情报服务新增真实 Key，也没有替用户确认商业/保存/再分发授权。

Windows、CAPE、双物理设备 P2P、不同目标内核 eBPF，以及四家 AI 官方模型完整验收不属于本次已覆盖范围。原有 4 项特殊环境测试未重跑。本轮 HTML/DOCX 报告有真实输出，未新增 PDF 生成引擎或实际操作打印对话框，PDF 仍沿用系统打印。

仅域名 RDAP；无 IP/ASN 注册查询、事件级外发策略、账户真实余额/扣费明细、完整历史 DNS、跨平台评分共识或自动归因。工作区查询记录仍明文，Hash 检查不能抵抗同时修改数据库和原件的人。普通 Docker 不等于专用恶意代码虚拟机。

报告结果摘要针对经过脱敏的规范化 JSON；不是对厂商原始 HTTP 的签名。厂商数据可能过时、错误或受再分发限制，必须结合现场证据和时间范围复核。
