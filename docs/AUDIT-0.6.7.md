# 嘎嘎安全助手 0.6.7 深度审计

本次采用代码阅读、故障注入、单元回归、真实 Docker 工具往返、macOS 原生 WebView 和实际文件/数据库核验。发现问题后修改实现；测试只使用无害或合成材料，没有执行真实木马。结果不构成“没有任何 bug”或全平台可用性保证。

## 修复与架构调整

| 问题 | 影响 | 修改与验证依据 |
|---|---|---|
| 隔离工具的所有异常都返回模型继续处理 | 摘要不符、错误协议或清理失败之后，仍可能利用旧工件形成完成草稿 | 区分可恢复拒绝与致命错误；完整性/协议/运行/清理异常终止；6 类假 Docker 故障分支验证 |
| 清理状态只反映 Pi 容器 | 工具容器清理失败可能被最终“已清理”覆盖 | 合并任务内工具清理确认；创建前安装守卫；部分创建失败仍尝试清理；删除前验证归属 |
| 同步写 Pi stdin | 不读输入的进程可能堵住取消和任务截止 | 专用有界写线程、写超时和取消轮询；进程组终止后释放管道；阻塞写故障测试 |
| 镜像仅判断存在 sha256 字样 | 错误版本镜像也可能显示就绪 | 完整摘要格式、当前版本标签和双向协议验证；按不可变镜像 ID 启动 |
| 容器配置验证不完整 | 新增能力、设备、共享命名空间未明确拒绝 | 补充 CapAdd、设备请求、VolumesFrom、PID/UTS/Userns、额外 tmpfs 验证 |
| 工具参数只依赖上游 schema | Worker 直接调用可能将错误类型默认为有效值 | 宿主与 Worker 各自验证操作、字段、类型和范围 |
| ASCII 连续串先截断再搜索 | 超长字符串后半段的 IOC 漏检 | 先全串匹配，再返回命中上下文及实际偏移、截断/省略数量；原生容器和共享纯函数回归 |
| ELF / PE 入口地址运算缺少溢出及区间限制 | 畸形头部可能 panic、映射错误或跨区域解码 | checked_add / checked_sub，检查可执行文件支持区间、架构/字节序；限制 WASM 输入窗口 |
| 任务列表快照覆盖进度事件 | UI 可能由完成回退为运行，或一直显示旧状态 | 递增 revision 合并，先订阅再快照，轮询补偿、事件过滤、组件卸载失效标记 |
| 镜像构建结果可能被迟到检查覆盖 | 刚构建完成仍可能显示未就绪 | 环境请求序号与明确检测状态，旧检查不覆盖新操作结果 |
| INSERT OR REPLACE 改变 rowid，取消依赖列表前 30 条 | 任务顺序不稳定，历史较多时取消目标可能找不到 | 主键 Upsert，按创建时间索引，直接按任务 ID 与事件校验取消；110 条历史回归 |
| 归档 Pi 原始请求与真正发送内容不同 | 排查模型行为时请求材料不准确 | 先按官方适配策略缩减 payload，再保存相同 JSON 正文及 SHA；记录模型/端点/配置版本/样本名称 |
| 报告只依赖延迟自动保存 | 保存失败或快速退出时最后文字可能丢失 | 即时本地恢复日志，成功回执只清自己版本，恢复版本冲突有显式操作；按工作区/事件隔离 |
| 页面非法脚本 URL 中断整次巡检 | 可采集的页面和其他脚本证据丢失 | 提取页面采集/子资源采集/名单匹配边界，逐项错误归档；相同失败仍显示覆盖受限 |
| 巡检完成重写整个旧 Asset | 并发启停或确认基线可能被覆盖 | 启停、基线、采集结果分别更新自己的 SQL 字段 |
| 缺少部分索引、Unix 新工作区权限较宽 | 关联查询成本增加，明文材料访问范围过大 | 增加截图/复核/任务索引；新目录 0700，数据库与快照 0600 |
| 远端自动调用存在未修复的 RSA 解密时序风险 | 持任务凭据的一方可能观察私钥解密时延 | 暂停在线生成和接收；后端先行拒绝，离线人工导入保留 |
| 通用 ZIP 解包与旧 Go 工具链公告 | 危险权限/符号链接恢复，以及旧标准库风险 | 固定条目安全解包及恶意归档回归；Go 基线升至 1.27.3 |
| 隔离模块承担过多职责、Worker/Agent 代码紧缩 | 权限和失败路径难以审阅 | 拆分 runtime / rpc / records / orchestration，Worker 纯工具模块；关键不变量、信任边界与恢复路径注释 |

注：版本标签提供兼容性校验，不等于可信签名。清理失败后再次清理成功，也不会追溯将此前未完成任务改成成功。没有把“不支持架构”解释为安全，也没有实现自动绕过反调试/沙箱检测。

## 剩余边界

- 本轮没有重新完成官方云模型端到端验证。已有 Key 保持在系统凭据服务；之前最终构建读取曾超过 30 秒未发送请求，本轮不提取 Key、不修改凭据 ACL。合成 Pi SSE 通过只说明工具/协议链路，不能替代四家官方模型验收。
- Windows 安装包运行、CAPE 真实虚拟机、真实 Linux 内核 eBPF 挂载仍需要对应环境；macOS Docker 的元数据采集与单元测试不能替代这些验收。
- 复杂样本没有真实检出率测试；四个静态工具不提供反编译、脱壳、内存取证、多 VM 自动运行或反分析规避验证。固定字符串是候选线索，静态无命中和动态未观察到都不证明安全。
- HTTP/日志/截图等部分解析仍在客户端，证据库及报告恢复日志为本机明文。没有多用户权限、不可抵赖审计链、数据库加密、自动备份、完整删除/保留策略。
- 当前单事件 Workspace 会加载证据摘要，尚未做千事件/百万证据并发容量验收；1 GiB 单文件流式检查不等于无上限容量。新增索引不替代分页架构。
- Cargo / Go 已完成 OSV 公告匹配和逐项审阅；仍有 RSA、ZIP 等锁定依赖公告，采取禁用远端解密和移除危险调用等措施，未声称漏洞清零，见 DEPENDENCY-REVIEW-0.6.7.md。npm 公告审计与功能测试不构成完整供应链安全证明；CI 配置已补全，远端矩阵尚未在本会话实际运行。
- 提供的 macOS 包为 ad-hoc 签名开发构建，尚未 Apple 开发者签名或公证；PDF 通过系统打印，未声称后台 PDF 生成已实现。

架构与数据流见 C4-architecture-0.6.7.md，贡献与检查命令见 ../CONTRIBUTING.md。
