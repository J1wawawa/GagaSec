# 0.7.3：报告后台导出与数据边界审计

2026-10-29，macOS arm64。定位不变：面向防御团队、运行在个人 PC 上的一站式安全终端。本轮先完善报告这一核心交付流程，不把整个工作台分页或所有长任务进度宣称为已经完成。

## 改动与原因

| 范围 | 审阅发现的旧行为 | 当前实现 |
|---|---|---|
| 事件归属 | 导出工作线程重新查询活动事件，不能用调用来源证明其最终读取哪个事件 | 新后台接口显式接收 case_id；兼容等待接口在派发前捕获事件 ID。读取阶段在同一数据库锁内捕获该事件正文、纳入节点、截图和引用证据，渲染不再查询活动事件 |
| 数据读取 | 导出调用完整 workspace 聚合，解析所有证据及 AI 历史，未引用证据也进入报告限制收集 | report_input.rs 只读取纳入节点及其实际引用。多个节点引用同一证据只校验一次，报告限制也只来自引用材料 |
| 长任务体验 | 只有统一忙碌提示，原件 Hash 校验没有真实进度或取消入口 | report_jobs.rs 管理单个活动任务和最近 20 次进程内结果；报告页显示真实读取字节、阶段、错误和取消，底部入口在其他页面仍可使用 |
| 文件提交 | 导出没有业务取消检查点，目标可误选为工作区内部文件 | 原件每 256 KiB 检查，正文节点/图片间、ZIP/HTML 写块和提交前检查。取消与进入最终提交共用锁；进入提交后拒绝取消，不假报取消。拒绝覆盖数据库、证据、截图及已知内部目录和符号链接目标 |

这些问题来自代码审阅和新增故障验证；未为旧版本人为构造并声称已实际复现所有竞态。后台输入在“读取报告快照”阶段捕获，捕获后编辑留待下次导出；不承诺点击瞬间原子冻结整个客户端。完整架构见 [C4-architecture-0.7.3.md](C4-architecture-0.7.3.md)。

## 本机验证

基础检查完成 106 项 Rust 测试，含事件快照/未选损坏记录排除、内部文件覆盖拒绝、取消/提交顺序、任务上限、写后取消仍保留旧输出和清理临时文件。Clippy -D warnings、rustfmt、TypeScript/Vite、Prettier、10 项前端状态断言和六项源码误提交检查通过。最终运行计数与压缩包摘要以随交付 verification.json 为准。

新增 tests/native-report.mjs 使用物理写入的 1 GiB 合成归档、1000 份零字节未选归档、两个引用同一大原件的节点和独立事件 B。材料是人工构造的导出压力夹具，不是日志分析器检出结果，也不代表真实入侵。**1 GiB 是报告引用的原件大小，不是生成的报告大小。**

该原生测试验证实际 WebView/IPC、校验字节去重、拒绝并行导出、切页继续使用、切事件仍显示原事件任务和取消、旧文件保留、HTML/DOCX 跨事件完成、拒绝覆盖数据库、双主题最低窗口，以及重启后文件保留而任务历史清空。首次 15 项、重启 3 项通过；物理检查 10 项包括 SQLite integrity/FK、原件 SHA、DOCX ZIP/XML/双节点/Hash、HTML 和临时文件清理。

开发构建实测取消约 53ms，HTML/DOCX 完成各约 21 秒；后者包含重新校验 1 GiB 原件，不能当作优化 release 构建或其他机器的性能保证。最终重跑的实际耗时记录在 native-report.json，计数不当作准确率。

最终同一可执行文件的深度回归通过首次 36 项、重启 5 项和物理工件 19 项，涵盖 HTTP、无害 PHP/ELF 隔离分析、Pi 取消、隐私锁、截图粘贴、报告、篡改拒绝、备份恢复及双主题。综合平台通过 181 项界面检查和 11 项持久化检查；真实后台客户端对 localhost 的 10 个合成资产完成两轮巡检，保存 20 份 HTTP 200 快照及 JS Hash，两轮分别约 10.3 秒和 75.4 秒完成（巡检间隔 60 秒），未调用外部 AI。固定测试证书的加密回传收到 HTTP 202。导航通过 115 项检查。这些合成/本机服务验证不替代真实客户资产、官方模型、目标内核或 Windows 验收。

## 测试过程中保留的问题记录

- 新夹具最初的节点 INSERT 占位符多一项，客户端尚未启动即失败；修正为十列匹配十个值。
- 新物理检查使用了当前系统 Python 不支持的 hashlib.file_digest；改成兼容的分块 SHA-256 后重跑，未跳过原件校验。
- 既有 Pi 取消测试等待 React 定期刷新，某次已进入一次代理尝试才取消。任务状态为 cancelled、清理确认、无报告，但“尝试次数为零”的断言失败。测试改为在任务记录出现后直接按 ID 调用真实取消 IPC，避免把 UI 刷新时机当成“凭据读取之前”的保证。保留失败日志；modelRequests 是代理尝试数，不能单靠它证明网络已发送或未发送。
- 综合平台首次 181 项界面检查通过，随后以直接执行二进制方式重启后台巡检时进程退出，未完成该阶段。测试 runner 将后台启动也统一为 Launch Services，再串行完整复跑：181 项界面、11 项持久化、10 资产两轮巡检及 115 项导航通过。保留 platform-background-before-fix.log；本次复跑证明统一启动方式下流程完成，未确认首次退出根因，不据此宣称已修复产品崩溃。

## 使用与维护边界

任务状态只存在当前进程，不进入备份；不提供断点续传、后台守护或自动重试。正常取消/失败清理本次临时文件，旧报告保留；强制退出或断电仍可能留下 .gaga-*.partial。正在同步/替换的文件系统调用不能即时打断，最终提交阶段不再接受取消。

数据库快照读取、单张图片解码/转码和其他有界步骤不是可抢占线程。当前正文和图片仍在内存编排，未验证数千张截图的大报告容量。工作台聚合仍会读取当前事件全部证据，未实现全工作台分页；1000 份未选证据测试不能代替千事件或长期巡检压力验收。

SHA-256 复核用于发现原件变化，不证明采集真实性、数字签名或司法级不可篡改。文件路径保护针对误选，不抵抗拥有本机权限的人并发修改路径、数据库和原件。工作区仍是明文存储。

本轮没有改动模型请求、Agent、eBPF 或动态沙箱。没有执行实际恶意样本或请求官方模型。0.7.2 的 DeepSeek 尝试因系统凭据授权超时在请求前失败；0.7.0 的官方调用、0.7.1 的 Go/eBPF 为历史结果。Windows GUI/Agent/凭据/CAPE 和另外三家官方模型仍待实机验收。

依赖公告数据库本轮未重扫；0.7.0 保留的 5 个 Rust 包匹配不因本次改动消失。macOS 仍是 ad-hoc 签名的开发包，未 Apple 公证，远端 CI 未执行。许可继续为源码公开、非商用免费、商用需 J4team 授权。

## 复现

```sh
npm ci
npm run check:source
npm run test:source-check
npm run format:check
npm run test:ui-state
npm run build
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test --locked --manifest-path src-tauri/Cargo.toml
npm run desktop:build:mac-dev
node tests/native-report.mjs /absolute/path/to/debug-executable /absolute/path/to/results
```

原生压力测试会在新建临时目录物理写入约 1 GiB 归档；不要指向客户工作区。仅 debug 的 --report-ui 使用明确合成夹具并记录原生验证，不启用后台调度，也不调用模型。其他报告、截图、备份恢复与平台回归记录随发布交付，历史验收保持原版本标签。
