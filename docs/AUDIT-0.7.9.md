# 异常恢复与数据保护审计 · 0.7.9

本轮针对上一版新增日志及既有输出/Agent 链路继续审计，使用合成材料复现和修复。日期 2026-10-30，以 macOS Apple Silicon 为实机基线；定位仍是个人 PC 上的一站式防御调查终端。

## 具体发现

| 问题 | 修复与回归 |
| --- | --- |
| 日志去重不区分任务、级别，相邻任务的同一错误或成功信息可能只剩一条 | 去重键包含任务和级别；原生连续两个成功报告各有独立 contextId |
| 写入之前更新去重缓存，落盘失败后立即重试可能被吞掉；错误状态不恢复 | 仅同步成功后更新缓存；失败不去重，成功后清除当前写异常。实际用错误文件类型模拟故障后恢复 |
| 末条 JSONL 被截断后，新记录直接粘连在半条旧记录后，读取时一起丢失 | 追加前补换行；保留旧字节，坏行跳过，新记录独立可读 |
| Rust Mutex 只管本进程，正式日志目录却由同用户多个进程共享 | 文件锁串行追加/轮转/读取，250 ms 有界竞争；真实子进程持锁拒绝与释放后重试 |
| 报告线程异常展开只留下错误，但含材料的临时文件可能残留 | 临时文件 RAII 守卫先关句柄再清理；用实际 panic + catch 验证旧报告保留、无 partial 残留 |
| LAN 身份/水印密钥及错误索引直接创建最终文件，普通写入失败可能留下半成品 | 完整写入并同步后排他提交，拒绝覆盖已有文件；实际两个线程同时发布，只有一个成功且赢家内容完整 |
| Agent ZIP 直接截断目标，数据库登记晚于写文件；登记失败会覆盖旧包却返回失败 | 共用保护路径和临时提交；登记失败保留旧包，文件提交失败补偿删除新任务。用 SQLite 拒绝触发器、目录目标及真实 ZIP 读回测试 |
| Agent 在保存窗口/钥匙串等待后读取当前事件，可能放到后来切换的事件 | 前端在保存窗口前捕获 caseId 和表单，后端显式检查并使用该事件；活动事件不同也不改变归属 |
| 输出保护遗漏升级前数据库快照目录，日志有任务 ID 但界面不能查找 | 保护 migration-backups / runtime-logs；报告失败显示任务 ID，日志可按 ID 搜索、显示、复制，原生最小窗口检查 |

前五项新增用例在修复前真实失败：日志 4 项、临时文件 1 项。不是只统计全量旧测试。其余通过新增故障注入、并发提交和事件归属回归验证。原始失败日志与最终结果随验收归档。

## 验证方式

Rust 共 137 项通过、4 项忽略（最终以交付清单为准）；包含新测试与既有 TLS、组播、采集加解密、报告、SQLite 与隔离工具协议回归。全目标 debug / release Clippy 检查 `-D warnings`，TypeScript/Vite、格式、源码卫生、接口目录漂移另查。

原生 WebView 使用独立临时工作区，检查日志按任务 ID 搜索、连续任务终态、Agent 内部路径拒绝、缺失事件拒绝、升级快照保护、索引排他输出及已有 PDF 流转/重启。缺失事件/内部路径测试在读取系统采集凭据之前拒绝；没有读取真实模型 Key 或运行恶意样本。已有导航、HTTP、举证、报告结构、启动与 LAN 再做同源码回归，实际断言数见验收 JSON。

18 页既有合成报告用新客户端实际写入水印后，再用独立 macOS PDFKit 打开并逐页比较文字和页面尺寸。PDF 仍由系统打印生成，本轮没有将文件可读测试冒充系统打印对话框自动化验收。

`file_commit.rs` 另外以真实 Mac / Windows GNU / Linux GNU 目标标准库做模块类型检查，只有 UUID 临时文件名生成替换为编译占位；没有链接或运行外平台完整客户端。它能检查新增文件系统/FFI 分支的类型，不能代替 Windows 实机、安装或权限验收。

## 未消失的边界

普通异常展开可执行 RAII 清理；SIGKILL、进程 abort、断电或目录权限变化时仍可能残留受限权限的 partial 文件。文件同步不代表已验证所有磁盘在突然断电下的目录持久性，不声称完全防断电数据损失。

SQLite 与文件提交是两种资源。Agent 先登记后最终提交，普通提交失败会补偿；进程在两步之间被强杀，仍可能保留未交付任务记录。若补偿失败会明确返回错误，需停用该任务并检查工作区。没有自动删除使用者其他已生成任务或原包。

本轮没有依赖升级，沿用上一版 PDF/ZIP 修复版本；OSV 复扫仍需保留匹配审阅，不宣称供应链风险清零。Mac 未 Developer ID 签名/Apple 公证；Windows/CAPE、双物理设备和官方模型完整端到端本轮未验收。原事件库及证据未整库加密，不能抵抗本机管理员。main.tsx 仍有拆分债务。
