# 分析任务与使用过程审计 · 0.8.0

日期：2026-10-30。平台：macOS Apple Silicon。基于[蓝队产品调研](BLUE-TEAM-DESIGN-RESEARCH-2026-10-30.md)，本轮先落实后台分析、真实进度和任务恢复，定位仍为个人 PC 上的一站式防御调查终端。

## 实际改变

日志、WebShell 与 PE/ELF 文件导入改为后台任务。底部有固定入口，可查看原事件、任务 ID、实际阶段、计数、有限发现预览和失败原因。切页不会停止扫描，完成也不会抢走当前页面；点击结果会恢复任务所属事件。报告任务、Pi 逆向任务仍沿用各自原有管理流程，没有冒充所有任务已经统一。

日志显示归档与扫描的实际字节、行数、结构化解析、未识别、跳过、命中和扫描均速。预览最多 24 项，原文与行号可核对，完整命中留在 SQLite 分页。静态样本显示隔离环境和工具阶段；规则发现只在工具报告返回并校验后展示，没有逐层实时解码或运行样本。

原始文件归档采用排他完整提交；扫描取消回滚索引，证据插入失败时补偿删除该次派生索引与快照。补偿失败会记录错误。取消与最终提交共享状态锁，进入最终保存后拒绝取消，避免结果已经入库却显示取消。隔离任务取消会终止自己的 CLI 进程组，之后清理本任务容器，不停止 Docker 引擎。

进度与状态按 revision 合并，防止迟到的初始响应覆盖新状态；前端轮询节奏也依据合并后的状态。持久化和推送最多每 200 ms 一次，任务阶段和终态立即保存。每事件保留 30 项任务、界面最多 80 项；空闲时快照查询降为约 15 秒。重启复核证据是否已提交，其余未完成任务标记中断，不自动执行。

## 故障与行为验证

新增五个 Rust 综合用例，覆盖归档/扫描取消、输入字节不变、暂存清理、索引回滚、预览上限、拒绝并发、事件归属、最终保存拒绝取消、证据插入失败、重启复核，以及无害 sleep 子进程组的实际终止。全量 142 项通过、0 失败、4 忽略；debug/release 全目标 Clippy 均以 `-D warnings` 通过。

前端状态回归共 25 项，其中新增 7 项分析任务合并断言。TypeScript/Vite、格式、84 项 IPC 目录漂移和 9 项源码规则另行检查。React vendor 单独分块，构建不再触发单块体积警告。

原生验收使用生成的 128 MiB 日志（1,328,902 行）及不会执行的 PHP 静态片段，检查完成前计数与原文预览、切页、事件切换、停止按钮、失败日志、真实 Docker 静态结果、最小窗口明暗布局与重启历史。输入 Hash 和文件/索引残留另由外部脚本核对。既有启动、LAN、HTTP、举证、报告结构、运行日志和 PDF 流转回归的最终断言数见交付 `本轮验收.json`。

安装盘以只读方式实际挂载，核对应用签名、版本、Applications 链接和所有文件 Hash。原生注入验收使用同业务源码 debug 包；release 不开放验收注入。源码、审计包和应用 ZIP 均解压核对。只交付白名单合成材料，不分享临时工作区、数据库、身份密钥、日志正文或模型配置。

## 范围与后续

本轮没有读取真实模型 Key、调用外部模型或运行恶意样本。普通 AI 仍是阶段与完整回答，未实现逐字流式回答；没有持续 tail 日志或全面自动还原攻击链。Windows/CAPE、双物理设备和四家官方模型完整端到端未验收。

原事件库和证据未整库加密，Hash 与只读属性不能抵抗本机管理员；Mac 包尚未 Developer ID 签名/Apple 公证。强杀、断电或磁盘失败不保证清理和状态写入完整。已有 main.tsx 仍需继续拆分。

依赖版本没有升级，沿用 [0.7.9 依赖审阅](DEPENDENCY-REVIEW-0.7.9.md)及当次公开公告快照，不把继承的扫描说成本轮复扫，也不声称零风险。完整架构增量与取消边界见[本地分析任务](LOCAL-ANALYSIS-0.8.0.md)，此前文件提交与日志机制见[0.7.9 C4](C4-architecture-0.7.9.md)。
