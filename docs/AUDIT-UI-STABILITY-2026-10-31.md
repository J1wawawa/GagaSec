# 嘎嘎安全助手 · UI 与稳定性增量审计

日期：2026-10-31。审计对象是迁移后的 macOS 客户端源码目录 `gaga-client`。本轮只处理可以在当前环境复现并验证的客户端问题，不把 Windows、CAPE、真实目标主机 eBPF 或官方模型账号验收写成已完成。

## 本轮修复

### 窄窗口顶部导航

顶部命令栏现在让主导航占用可伸缩空间，并在导航项超出宽度时使用无滚动条的横向滚动。品牌、事件、模型和设置操作区保持固定，不会因为工作区数量增加而把右侧入口挤出窗口。现有 960×660、1024×720 和更宽桌面尺寸的布局回归仍以原生验收脚本为准。

### 窗口隐藏时的后台刷新

局域网状态、平台巡检、逆向任务、本地分析和在线情报列表的轮询现在在窗口隐藏时暂停或降为低频等待；收到原生事件仍可更新内存状态，窗口恢复可见时立即同步。Dashboard 的后台事件刷新也遵守可见性边界。报告导出任务保留后台轮询，避免隐藏窗口时导出任务停滞。

这项策略降低了客户端长时间放置时的 IPC、SQLite 和网络查询压力，也避免多个页面同时隐藏时持续争抢数据库。页面销毁会清理定时器和 `visibilitychange` 监听，避免切换事件或工作区后重复订阅。
