# 嘎嘎安全助手 · 深度边界审计

日期：2026-11-01  
对象：`gaga-client` 0.10.1，当前验收平台为 Apple Silicon macOS。  
目的：检查正常功能测试不容易触发的路径竞态、文件替换、并发资源上限、隔离边界和证据可信度问题。

## 本轮检查范围

- 证据导入、HTTP/告警粘贴、日志索引、截图与报告水印的文件读取和临时文件提交。
- Agent 加密回包的去重、重试、`collector-inbox` 持久化和 HTTPS 接收端。
- 局域网 P2P TLS 服务端的并发连接上限。
- 运行日志跨进程锁、轮转和错误重试。
- Docker/浏览器容器边界、页面监控、报告导出和本地明文工作区的现有限制。
- Rust 单元测试、Clippy、前端源码卫生、安全检查、IPC 文档和生产构建。

## 本轮修复

### 1. 证据和用户选中文件不再跟随最终符号链接

此前证据快照已经有入口检查，但多个“读取后再分析”的入口仍使用普通 `File::open` 或 `metadata`。在本机工作区被其他进程并发替换时，检查和打开可能落到不同对象。

现在 `store::open_regular_read` 在 Unix 使用 `O_NOFOLLOW`，并在打开前拒绝符号链接、目录和特殊文件。它已用于：

- HTTP/情报文件预览；
- 日志原件完整性校验和样本回读；
- 报告 HTML、DOCX、PDF 水印查询与 PDF 加盖前读取。

新增了水印符号链接回归测试；原有证据符号链接测试仍要求导入失败且不生成证据。这个保护针对应用边界和常见竞态，不能抵抗拥有工作区目录写权限的管理员直接篡改数据库或文件。

### 2. 临时材料和采集回包使用完整文件提交

HTTP/告警临时输入、结构化记录、证据快照此前已改用 `file_commit`。本轮继续处理 Agent 回包：

- `collector-inbox` 目录必须是普通目录，拒绝目录链接；
- 同一任务序列允许重试覆盖已有普通文件；
- 目标如果是符号链接或目录则拒绝；
- 内容先写入 0600 临时文件、同步，再通过原子替换发布。

回归测试验证预置链接不会改写外部文件，普通文件重试可以得到完整的新包。

### 3. LAN 和 HTTPS 接收端并发上限改为原子抢占

原来的 `load() >= 4` 后 `fetch_add(1)` 存在竞态，多个连接可同时观察到同一个空位。现在用 `compare_exchange` 循环在一次原子操作中预留槽位，连接结束仍然释放。两个服务端各有并发压力单元测试，32 个并发尝试最多成功 4 个。

### 4. 运行日志追加拒绝最终符号链接

运行日志锁和当前日志文件在打开时使用不跟随链接的选项。这样预置 `journal.lock` 或 `runtime-0.jsonl` 链接不会把锁或日志追加导向工作区外部路径。原有跨进程锁、轮转、截断尾行和失败重试测试继续通过。

### 5. 工作区布局在打开时拒绝链接

工作区根目录、`evidence/`、`screenshots/`、`workspace.lock` 以及 SQLite 主文件和 WAL/SHM 旁路文件现在在打开阶段检查类型。预置的链接或异常目录会让工作区打开失败，避免客户端初始化时把证据、锁或数据库操作导向工作区之外。新增回归测试覆盖链接证据目录和链接锁文件。

## 仍然存在的架构限制

这些是边界条件或部署条件，不能通过本轮客户端单元测试宣称已经解决：

1. **浏览器 DNS 重绑定**：页面监控在请求前阻断常见私有、回环和元数据地址，并限制跳转和同源 JS；浏览器实际 DNS 解析与检查仍存在重绑定窗口。不能把它描述成绝对 SSRF 防护，生产巡检应放在专用网络/虚拟机。
2. **Docker context 信任边界**：预检固定 context 名称和镜像 ID，但无法仅靠客户端证明 context 永远指向本机或专用隔离 VM，也不能消除预检到执行之间的 TOCTOU。动态样本必须在可丢弃、可回滚的专用 VM 中运行；普通 Docker 共享宿主内核。
3. **证据库不是 WORM**：SQLite、原始证据和部分派生材料仍是本地明文。工作区权限和 SHA-256 能减少误改并发现普通篡改，但不能抵御本机管理员同时修改数据库和原件，也不提供第三方不可抵赖签名。
4. **跨平台和外部服务未在本轮验收**：当前实机证据只有 Apple Silicon macOS。Windows 客户端、CAPE 虚拟机、真实 Linux 内核 eBPF、两台物理设备跨网络 P2P，以及 Qwen/GLM/Kimi/DeepSeek 四家官方账号的完整端到端调用仍需对应环境单独验收。
5. **规则、AI 和页面变化的语义边界**：命中规则、AI 结论、未命中容器基线或页面差异都只是线索/分析结果；没有原始请求响应、主机回执、时间依据或截图举证时，报告必须保留未知和待复核状态。
6. **长期容量与恢复窗口**：当前分页、上限和备份恢复有回归覆盖，但跨多年、多事件、持续流量和磁盘损坏场景仍需要在发布前做专门压力与恢复演练。
