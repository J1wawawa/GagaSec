# 0.6.7 依赖公告审阅

2026-10-28，使用 OSV 公共 API 扫描 Cargo.lock 注册表包、Agent 生产包实际选择的 Go 模块与 Go 标准库；同时运行两个 npm 锁文件的 npm audit。原始匹配与公告正文保存在本轮验收资料。匹配不是调用可达性结论，没有将尚存公告统一忽略。

## 已采取的措施

- RSA 0.9.10 / RUSTSEC-2023-0071：上游公告指出最新稳定版与 0.10 候选版仍受影响，随机盲化不能修复 padding 计时侧信道。暂停在线任务生成和 HTTPS 接收；后端在读取私钥、监听端口前拒绝，UI 同步禁用。保留离线人工导入，不能为远端提供自动解密或时延反馈。恢复前须审查新封装协议、迁移与兼容性。
- rustls-pemfile 2.2.0 / 停止维护：移除依赖，使用 rustls-pki-types 的 PemObject API；新锁文件不再包含该包。
- zip 2.6.1 / RUSTSEC-2026-0367、0368、0369：公告涉及通用解包恢复特殊权限和符号链接。产品写 ZIP 报告/任务；debug 采集验收原有的两个通用 extract 调用已替换为固定三个文件的受限读取，拒绝符号链接/非普通文件，限制大小、create_new、固定 0600/0700，不恢复外部权限。恶意 SUID/符号链接归档回归通过。锁定库仍有公告，未声称已升级；后续升级须覆盖 DOCX/任务包兼容性。
- Go 1.27.1：OSV 匹配 14 条标准库公告，其中 13 条修复于 1.27.2，证书信任公告修复于 1.27.3。Agent 构建最低版本提高到 1.27.3，重新执行 vet、race 测试并构建三平台模板；CI 按 go.mod 安装版本。生产包依赖模块未命中本次扫描公告。

## 保留并说明的匹配

| 包 / 公告 | 审阅与范围 | 剩余工作 |
|---|---|---|
| block-buffer 0.10.4 / GHSA-qwgh-2vcv-g2f7 | 公告 PoC 需要将游标内联于数据块，并在回调 panic 后继续使用。锁定 0.10.4 的 BlockBuffer 使用独立 pos:u8，未含公告 ReadBuffer；仓库没有 catch_unwind 后复用缓冲的调用。与公告所示损坏机制不一致。 | OSV 范围仍匹配，不将代码审阅当成上游修复证明；继续跟踪澄清和兼容升级。 |
| glib 0.18.5 / RUSTSEC-2024-0429 | GTK / Linux 目标的 VariantStrIter 存在不健全行为；本机 macOS Cargo tree 不选择 glib。Windows 目标树因本地缺少 webview2-com-sys 缓存未完成核对。 | 本版交付 macOS，不发布 Linux 安装包；Linux 支持前升级/修复并实测。Windows 构建仍由对应环境验收。 |
| fxhash 0.2.1 / RUSTSEC-2025-0057 | 停止维护通知，当前依赖链间接使用。不是一次已证实的产品漏洞。 | 跟随上游解析器/选择器依赖升级替换。 |
| proc-macro-error 1.0.4 / RUSTSEC-2024-0370 | 停止维护通知，构建依赖链。 | 跟随上游升级；不把构建期依赖等同于无风险。 |

离线导入仍使用 RSA，证据库、恢复草稿及解密材料为本机明文；当前无多用户身份或数据库加密。容器基础镜像系统包和 vendored 工具的完整 SBOM、签名来源验证与系统级漏洞扫描尚未完成，npm/OSV 结果不能替代这些检查。

## 复现

Python 3.11+、受支持 Go 工具链和网络：

```sh
python3 scripts/audit-dependencies.py /tmp/gaga-dependency-audit
npm audit
npm --prefix reverse-worker audit
```

脚本只发送依赖名称/版本，不读取工作区、凭据或客户样本。网络失败直接报错，不把未完成扫描标为通过。OSV 结果随查询时间变化；审核本次交付时以附带原始 JSON 和构建摘要为依据。
