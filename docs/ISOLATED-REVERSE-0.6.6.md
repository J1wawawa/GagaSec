# 0.6.6 隔离静态分析与 Pi 辅助逆向

入口为「样本分析 → WebShell 分析 / 样本静态分析」，包含「静态结果」「Pi 辅助逆向」「隔离环境」三个页签。报告仍有独立一级入口。

## 使用

1. 启动 Docker Desktop，在「隔离环境」检查并构建 `gaga-analysis:0.6.6`。首次构建需要下载 Linux Rust / Node 基础镜像与锁定的 npm 依赖。Rust 工作器依赖以含许可证的 vendor 归档随源码提供，构建不访问 crates.io。
2. 导入脚本（最多 8 MiB）或可执行样本（最多 128 MiB）。客户端只归档原始字节和 Hash；静态解析在隔离容器执行。没有 Docker / 镜像会停止，生产二进制没有宿主机 Goblin 样本解析器。
3. 在 Pi 页签选择当前事件的样本、填写调查问题。使用设置中保存的 DeepSeek / Qwen / GLM / Kimi 官方配置。启动后，调用的样本片段及工具输出会发给所选官方模型，不是离线推理。
4. 查看「调用过程」与「工具举证」。结果可加入事件时间线，在独立报告页的第 3 步「事件过程排查」关联节点、负责人、时间与截图。报告可编辑并导出 HTML / DOCX，PDF 仍使用系统打印。

## 实现边界

Pi Agent Core 与 Pi AI 固定为 0.73.1，仅注册四个工具；没有完整 coding-agent 的 shell、文件系统工具、扩展、项目指令或技能加载。任务不执行样本。

| 工具 | 输出及限制 |
|---|---|
| `read_metadata` | 隔离静态规则 / PE、ELF 基础结构、有限导入与字符串；工具视图至多 30 项发现、每条附加信息 6000 字 |
| `read_source` | 脚本原文行号，每次最多 120 行、18000 字节，单行 1200 字符；不能读取其他文件 |
| `search_strings` | ASCII 字符串与文件偏移；最多 100 个结果、单条 300 字节 |
| `disassemble` | iced-x86 WASM 线性解码，仅 x86 / x64 PE / ELF 入口附近；每次至多 160 条、4096 字节，入口增量不超过 16384 字节 |

这不是反编译、自动脱壳、AST / 污点分析或完整控制流恢复。未命中保留未知；静态字符串、导入和反汇编不能证明行为已执行，也不能证明攻击者归属。ARM 可做基础元信息检查，反汇编明确报告暂不支持。

## 隔离与密钥

每次静态工具调用使用新的临时容器。原始字节通过标准输入传入 `/tmp/sample`，工作器按只读文件处理；不挂载样本目录。Pi 使用另一个容器，仅接收任务信息与受控工具结果，不直接获得原始样本文件。

容器在启动前由 Docker inspect 校验：`network=none`、只读根、UID/GID 65534、cap-drop ALL、no-new-privileges、IPC none、无卷或 bind mount、768 MiB 内存、1 CPU、64 进程；`/tmp` 为 192 MiB 的 noexec/nosuid/nodev tmpfs。不挂载 Docker socket、宿主机目录或凭据。

容器和可信控制器通过 Docker attach 的标准输入输出交换 JSON 行；没有模型网关监听端口。Pi 发出模型请求体，Rust 控制器验证保存配置的 revision、四家官方端点及型号、工具名单、材料和响应上限；从系统凭据服务读取 Key，仅用于 HTTPS 请求头。重定向禁用；真实 Key 不进入容器、数据库、提示词或工件。Pi 的占位 Key 不具备认证能力。

所有解析器均可能存在漏洞，Docker 共享内核，以上措施降低暴露而不构成绝对隔离。真正动态运行未知木马仍应使用独立、可回滚、无宿主机共享目录的 Linux / Windows VM；现有 CAPE 接口尚缺 Windows 实机验证。本次没有执行真实恶意样本。

## 任务、证据与故障

单客户端同时运行一个 Pi 任务，单次工具串行；最多 8 次模型请求、16 次工具尝试、300 秒。模型请求支持取消，正在运行的工具最多等待当前 45 秒调用结束。模型输出到长度上限、工具未调用、格式错误或预算耗尽均不能标记为完整成功。

任务绑定创建时的 caseId 与 evidenceId；切换事件不会把完成结果写到新事件。每次工具调用校验归档与返回样本 SHA-256，保存参数、JSON 工件 Hash、预览；完整工件与模型请求正文分别保存在 `reverse-artifacts/<job-id>/`。原始材料、派生分析、调查节点分别保存。

正常、取消和失败路径均尝试删除任务容器；清理失败在状态中保留，环境页只清理本工作区标签的遗留。异常退出后运行中的记录标记失败，不自动重试或重跑样本。工件与任务历史按事件保留；模型请求材料包含样本片段，应按事件证据管理。

## 验证方式

`scripts/test-isolated.py <新输出目录>` 使用无害脚本和合成 x64 ELF，实际创建禁网容器，验证元信息、行号、字符串偏移、WASM 反汇编、非法参数、容器写入/网络/凭据边界，以及真实 Pi SDK 的合成 SSE 工具往返。

开发版 `--reverse-ui <独立工作区>` 在原生 Tauri WebView 中运行 `src-tauri/tests/reverse-ui.js`。工作区只复制已保存的官方模型配置元数据，Key 仍由系统凭据服务读取；实际官方调用与合成 SDK 传输测试分别记录。不能把合成响应当作真实模型验收，也不能把两份无害样本的通过当作复杂恶意代码检出率。

反调试与沙箱规避的能力边界和后续策略见 [反分析说明](ANTI-ANALYSIS.md)。
