# 0.7.5 macOS 便捷性专项验收

范围是新增举证、报告返回来源、证据筛选分页和环境引导。已有 0.7.4 结果保留为历史基线，不将其全部标成当前构建重新验收。本轮不读取真实 Key、不访问官方模型、不执行真实恶意样本；Windows / CAPE 仍未验收。

新增事务回归 5 项：重复提交与重启、报告版本冲突、章节满额回滚和图片清理、跨事件与不存在的发现、坏图拒绝与已有负责人保留。Rust 全量结果为 112 通过、1 项显式存储压力测试按原配置忽略；本次未重跑该累计压力测试。前端状态断言 18 项，类型构建、格式、Clippy 禁止警告和源码检查通过。

真实 macOS WebView 专项首轮 19 项、重启 3 项：

- 手动录入合成 HTTP 请求与响应，不使用生产内置样例入口。
- 在同一窗口新建报告章节、填负责人、模拟系统图片粘贴及图注，再保存；保持当前分析页。
- 白天、夜晚主题在 960 × 660 最小窗口验证举证布局无横向溢出。
- 二次记录选择已有章节并打开报告，不覆盖原负责人。
- 报告正文保存后返回原证据，确认 HTTP 材料正确。
- 报告恢复日志存在时，刷新目录清除旧关联选择。
- 26 份合成证据按 24 / 2 行分页，Hash 搜索、已关联和未关联筛选符合结果。
- 一次检查呈现四类环境状态，并可跳到模型设置。
- DOCX 输出成功；重启后节点、原图、图注、章节引用与正文仍可读取。

脚本位于 `src-tauri/tests/usability-ui.js`。仅 debug 隔离模式 `--usability-ui <临时工作区>` 可执行，工作区准备 `phase.txt` 为 `first` 或 `reopen`。以 `native-ui-verification.json` 实际通过项和错误为准；无凭据调用并不代表官方模型验收。

界面自动化使用合成材料与粘贴事件，不代表对所有系统剪贴板来源、无障碍读屏器和长时间使用均完成验证。界面搜索为前端分页；动态样本仍要求专用隔离虚拟机。Mac 为开发签名，未 Apple 公证。

发布素材另含约 5600 字公众号稿、两种封面、功能配图、30 秒无声示意动画及社区投稿包。排版在 390px / 760px 下检查无横向溢出，视频完整解码通过；它们不是客户端操作实录，也未自动向公众号发布。
