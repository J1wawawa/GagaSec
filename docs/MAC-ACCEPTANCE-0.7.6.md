# 0.7.6 Mac 局域网协作验收

日期：2026-10-29。平台：Apple Silicon macOS。版本：0.7.6 开发预览版。

本轮验证局域网协作及本地保存，不重新声明所有历史模块通过验收。数据均为合成材料，没有读取真实模型 Key、调用外部模型、运行恶意样本或修改防火墙。

## 自动化与真实网络

Rust 全套：122 通过、0 失败、4 忽略。忽略项保留原有需要额外环境的条件，不计入通过。局域网模块使用本机不同临时工作区、真实 TCP/TLS 和 UDP 组播；没有用固定返回值替代网络服务。

本轮覆盖：

- 发现未配对设备，发现数据不自动建立信任。
- 一次性邀请与双向 TLS 1.3；错误证书、未配对、过期邀请和冲突消息 ID 拒绝。
- 双向文字、Unicode 表情、文件、PNG 截图、两帧 GIF 原字节传输及 SHA-256 核对。
- 附件先提供接收选项，确认后下载；保存回执与仅通知送达分开。
- 重试去重、附件密文损坏拒绝、取消配对后旧凭据被实际服务端拒绝。
- 重启后身份、联系人、正文和图片可解密恢复；中断发送/下载转为可手动重试状态。
- 通用事件备份排除聊天、配对及私有身份文件，复制出的数据库清理后整理。

## 原生界面

重新构建签名后的 `.app`，以独立合成工作区执行原生 WebView 首次运行 14 项与重启 3 项检查，逐项结果随验收包交付。测试伙伴也使用独立工作区与真实局域网服务。验收入口仅调试构建的显式验收模式可用，普通工作区不显示创建测试伙伴或注入测试消息入口。

检查包括独立入口、默认关闭、组播发现、邀请配对、文字与表情落到真实对端、入站回复、截图预览与接收回执、文件明确接收及导出、GIF 显示、960×660 明暗主题布局、关闭对端后的离线超时、关闭协作保留历史，以及重启后联系人/文字/文件/PNG/GIF 保留且不自动监听。

粘贴验收是在原生 WebView 派发含图片 File 的 ClipboardEvent，运行真实产品粘贴处理、预览和网络发送；没有自动操作系统截图快捷键及系统剪贴板。系统文件选择器与权限弹窗仍需双机人工体验验收。

代码检查：TypeScript/Vite、Prettier、Rust fmt、全目标 Clippy `-D warnings`、源码卫生扫描及 8 项卫生规则回归通过。源码检查新拦截 `lan-private` 下的身份及聊天文件，包括忽略规则下被强制跟踪的文件，不输出匹配内容。

## 本地保存实况

| 数据 | 当前保存方式 | 备份与限制 |
| --- | --- | --- |
| 事件、报告草稿、节点、分析结果 | SQLite | 通用工作区备份/恢复；未整库加密 |
| 原件及截图 | 工作区文件归档、Hash 校验、新导入只读 | 保留原始材料；仍为明文，管理员可改权限或删除 |
| 聊天正文、联系人配对凭据 | SQLite 内 AES-256-GCM 密文 | 通用事件备份排除；无独立聊天备份界面 |
| 聊天附件 | `lan-private/attachments` 内 AES-256-GCM 密文 | 显式另存为普通明文副本 |
| LAN 身份和数据密钥 | `lan-private/identity.json` | Unix 目录 0700、文件 0600；当前用户/管理员可读，没有硬件封装 |
| 消息索引元数据 | SQLite 的时间、类型、状态、联系人关联等 | 未加密 |

聊天保留在原工作区；不要删除私有身份文件。没有聊天密钥迁移界面，丢失原工作区密钥无法解密旧聊天。该方案不能提供不可发现、不可修改或永久不可删除的保证。

## 尚未验收或未实现

- 尚未在两台物理 Mac、Windows、不同路由器或有 AP 访客隔离的网络联调；同一台 Mac 的真实服务联调不能替代这些验收。
- IPv4 同网段发现；不支持 IPv6 发现、公网中继、NAT 穿透、离线代收、群聊、已读或断点续传。
- 文件最多 32 MiB，图片最多 8 MiB / 4096×4096；GIF 最多 128 帧、累计 32M 像素。消息每批 50 条，界面最多展示 500 条。
- 不自动打开附件、不自动导入对方调查记录；可主动发送导出的报告或事件备份文件。
- Mac 包为完整 ad-hoc 签名的开发包，未 Apple 公证；Windows 安装包没有本轮实机结论。

使用步骤和协议见 [C4 与使用说明](C4-lan-0.7.6.md)。
