# 0.7.7 Mac 启动与交互验收

日期：2026-10-29。平台：Apple Silicon macOS。版本：0.7.7 开发预览版。

本轮关注启动、局域网通讯及其对原有工作流的影响。没有读取真实模型 Key、调用外部模型、运行恶意样本或修改防火墙、系统隐私设置。客户端由 macOS Launch Services 启动完整 `.app`，不以终端直接启动可执行文件替代图形应用环境。

## 启动是真实状态

六个阶段分别是检查工作区、加载数据库、加载安全组件、注册本地服务、恢复事件与配置、装配工作界面。前四步在 Rust 后台执行，最后两步等待 IPC 读取与 React DOM commit。数据库慢时窗口先显示当前阶段；初始化结束后才允许业务 IPC 与交互。

用真实 SQLite 排他锁阻塞初始化，确认页面仍可响应；释放锁后进入工作台。用无效 SQLite 文件确认失败页保留阶段和原始错误，不能点“跳过”进入空库；磁盘文件原字节另行 Hash 验证保留。实际隐藏原生窗口，确认即使 WebView 暂停动画帧，UI 仍能装配完成。

重播只展示本次已完成步骤、真实耗时和视觉运动，不重新打开数据库。动画默认补足约 1.1 秒视觉时长；可关闭、收起，并尊重系统减少动态效果。发生于 WebView 创建之前的原生崩溃不能由前端错误页覆盖。

## 自适应与视觉

启动页和 LAN 页在请求窗口 960×660、1100×720、1320×860、1600×1000 下检查浅色/深色，实际 WebView 可见尺寸记录在结果中（系统标题栏占用高度）。导航与报告等工作流另检查最小窗口。LAN 的配对弹窗、长文件名、长无空格文本、表情面板和固定输入区均覆盖。

这证明所列场景无横向撑开或关键控件越界，不代表所有字体缩放、显示器、系统缩放及辅助功能组合均验收。客户端最小窗口为 960×660，不以手机浏览器布局作为本轮目标。

## 通讯与保存

同一台 Mac 的两个独立合成工作区使用真实 UDP 组播与双向 TLS。验证文字/Unicode 表情、PNG 截图预览、GIF、显式接收文件、SHA-256、保存回执，以及重启身份/历史/图片恢复。对端关闭后在线状态到期；关闭本机协作后保留历史且不监听。额外 Rust 回归验证对端已保存/拒绝但回执丢失后，查询状态可恢复结果且不重复插入。

截图粘贴在原生 WebView 使用含图片 File 的 ClipboardEvent；没有自动操作系统截图快捷键、系统剪贴板或系统文件选择器。macOS bundle 有局域网用途说明，发现收发异常可显示原因。若权限、访客 Wi-Fi 隔离或路由器策略阻止流量，程序不会绕过。

聊天正文、配对凭据、附件为 AES-256-GCM 密文；时间/类型/状态等索引元数据未加密。密钥仍由本机文件权限保护，当前用户/管理员可以读取。原事件数据库和原始证据未整库加密，也不能保证不可发现、不可修改或不可删除。普通事件备份排除聊天与密钥，尚无聊天独立备份或密钥迁移界面。具体边界见 [LAN 架构](C4-lan-0.7.6.md)。

## 未由本轮证明的能力

双物理设备、Windows、CAPE 虚拟机、不同网络拓扑和系统权限弹窗仍需实机验收；四家官方模型以实际连接测试记录为准。P2P 当前不含群聊、公网中继、NAT 穿透、离线代收或断点续传。Mac 交付为 ad-hoc 签名开发包，未 Apple 公证。本轮不重新声明所有历史功能、长期负载或所有恶意样本都通过。
