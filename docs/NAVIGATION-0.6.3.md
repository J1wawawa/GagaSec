# 嘎嘎安全助手 0.6.3 导航改版

J4team · 2026-10-28 · Apple Silicon macOS 开发预览版。

原先四个大类把日志、HTTP、告警、容器和样本分析集中在同一组，样本案例库与分析入口分离。本次按任务拆为八个入口，保留顶部导航、固定内容区、事件选择与模型状态。

| 顶部入口 | 独立功能 |
|---|---|
| 总览 | 调查数据与待复核状态 |
| 事件调查 | 事件列表、证据资料、事件时间线、报告编排 |
| 日志分析 | 日志导入、原文举证与攻击时间线 |
| HTTP | 请求与响应联合分析、HAR、AI 复核 |
| 告警研判 | 原文录入、依据核对、AI 分析与追问 |
| 采集排查 | 采集 Agent、容器排查 |
| 样本分析 | WebShell 分析、样本静态分析、动态行为分析、样本案例库 |
| 持续监控 | 资产页面监控、重点主机流量 |
| 威胁情报 | 本地情报库、黑白名单、情报线索提取 |

每组最多四个工具，切回时保留组内最近位置。右上角环境检查与设置独立保留，悬停与无障碍名称说明用途。「全部工具」提供 21 个独立入口、用途摘要和关键词搜索；⌘K / Ctrl+K 打开，方向键选择、Enter 进入、Esc 关闭并恢复焦点。已有弹窗时快捷键不抢占输入。搜索区内部滚动，背景保持固定。HTTP 草稿在跨功能切换后保留。

## 本轮针对性实测

- 交付 .app 原生导航：109 项通过，覆盖八个任务入口、20 个功能页、最小窗口的明暗主题、组内位置记忆、工具发现、搜索、键盘事件、已有弹窗与草稿保留。
- 同一交付 .app 的 HTTP 原生回归：20 项操作和 7 项 SQLite / 原始文件检查通过。
- 同一 .app 打开既有真实采集工作区：16 项通过，包含 1 GiB 归档日志、尾部登录与 sudo 依据、容器采集缺失项、WebShell 对照与时间线举证。此次没有重跑 1 GiB 扫描、Docker 收集或恶意代码执行。
- 浏览器导航布局：127 项通过；1320×860、1100×760、960×660，明暗主题。全部顶部按钮完整显示，无横向导航滚动；工具面板独立滚动。
- 既有平台页面布局：44 项检查、60 个视图组合通过，包含资产、Agent、流量、情报、设置、HTTP 与动态观察。
- TypeScript / Vite、Tauri .app 打包、Prettier 与 cargo fmt 均通过。

原生测试使用真实 Tauri WebView、Rust 与独立 SQLite，输入和快捷键采用 DOM 事件注入，不能计为物理系统键盘操作已人工验收。截图明确为浏览器预览。0.6.2 的全量业务验收没有在本轮重复，也未增加 Windows / CAPE 或其他官方模型接口的实机通过声明。既有未实现能力见 `gaga-acceptance-0.6.2.md`。

导航实现集中在 `src/Navigation.tsx`，模块渲染仍由主界面连接原有功能。增加了隔离开发模式 `--navigation-ui`，用于对交付二进制复现检查；普通客户端不开放验收命令。

可复现：`node tests/native-navigation.mjs /绝对路径/嘎嘎安全助手.app/Contents/MacOS/gaga-security-assistant`，HTTP 使用 `tests/native-http.mjs`。浏览器补充使用 `tests/navigation-layout.mjs` 与 `tests/layout-platform.mjs`，需本地 Vite 与独立 Chrome 调试端口。
