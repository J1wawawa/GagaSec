# 跨平台局域网群组与通知

macOS 和 Windows 共用同一 JSON 帧协议、TLS 1.3、配对凭据和证书指纹固定。群组没有中心服务器：创建者从已配对联系人中选择成员，发送时通过每个成员现有的 TLS 单播逐一投递；每个成员按 messageId 去重并加密落盘。

初版预置类型为处置组、封禁组、研判组，也允许自定义组。通知可以关联 caseId 和 actionId，支持处置审批、执行、回执、失败、回滚和验证等状态主题。群组成员变更需要显式操作，未配对设备无法发送群消息或通知。

lan_state 返回 groups、groupMessages 和 notifications；lan_action 支持 group_create、group_text 和 notify。群消息和通知与联系人、附件同属 LAN 私有数据，工作区备份会排除这些记录。文件仍使用原有大小限制、SHA-256 和接收方确认。

聊天页提供“恢复历史”按钮。它只对在线、已配对的伙伴发起有界分页拉取，按消息 ID 去重并以本机 LAN 密钥重新加密落盘；重复点击不会覆盖或复制记录。文本会恢复原始时间，附件先恢复为待确认元数据，用户确认后才下载内容。新客户端若原身份丢失，需要先重新配对；恢复不会绕过配对权限，也不会自动删除本地记录。

当前开发环境只有 macOS。协议和 Rust 单元测试覆盖跨平台数据格式，Windows 实机防火墙、局域网权限和多设备联调需要在 Windows 环境完成后再标记为已验收。
