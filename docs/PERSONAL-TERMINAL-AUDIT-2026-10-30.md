# 嘎嘎安全助手 0.10.1 · 个人蓝队终端审计与调研

日期：2026-10-30。审计对象是 macOS Apple Silicon 客户端和仓库中的本地分析/Agent 组件，目标是判断它能否独立支持一次个人蓝队调查。结果不等同于渗透测试、密码学审计、供应链审计、检测率基准或安全认证。

## 结论

0.10.1 可以作为 **macOS 个人蓝队调查开发预览版** 使用：事件隔离、原始证据归档、摘要校验、HTTP 请求/响应联合分析、日志线索时间线、WebShell 分层静态分析、容器覆盖检查、IOC 与报告节点、截图举证、HTML/DOCX 输出、可选官方情报查询和运行错误记录已经形成一条可走通的本地流程。

它还不能称为跨平台稳定生产终端，也不能承诺“完整攻击还原”“全面取证”“木马动态行为已观察”或“AI 自动判定正确”。只有 Mac 实机在当前环境验收；Windows/CAPE、真实 Linux 目标内核、双物理设备 LAN 和四家官方模型账号没有在本轮通过。普通 Docker 共享内核，不能替代专用可回滚虚拟机。

## 与公开响应流程的对照

本轮读取并保存了 NIST SP 800-61 Rev. 3、CISA 联邦事件响应手册、Timesketch 基本概念、Velociraptor 离线采集说明、Sigma 规则基础和 DFIR-IRIS 案件说明。依据是公开文档的工作流要求，不是把这些项目的代码或许可证带入本项目。

NIST 的重点包括：按风险而非先到先得进行分级；每个事件记录负责人、指标、动作状态、预计时间和下一步；建立事件发生的资产序列和根因；记录调查动作并保存完整性与来源；验证备份后再恢复并确认恢复结果。Timesketch 把一个 case/sketch 作为多条时间线和视图的容器，并明确提醒时间线存在时钟偏差和解释限制。Sigma 要求规则的状态、作者、日期、误报说明和许可证可追踪。Velociraptor 的离线采集强调采集器版本、工具和回包元数据的可复核性。

项目已经覆盖了其中的事件负责人/章节/节点/截图、原件摘要、事件隔离、报告快照、备份恢复校验和规则命中说明的一部分；以下差距仍会直接影响调查结论的可信度。

## 仍需优先补齐的能力

### P0：公开稳定版前

1. **把“规则命中时间线”明确升级为“可解释的多源时间线”**：目前日志索引的是本地规则命中行，未命中原文仍在归档中；缺少原文上下文按行号读取、时钟偏移/来源时区显示、同一主机/IP/账号的实体关联，以及“未采到、未检查、超限、失败、未命中”的独立状态。报告必须能显示筛选范围和数据缺口，不能把零命中写成安全。
2. **建立处置回执闭环**：记录建议、审批人、执行人、开始/结束时间、目标、实际回执、失败原因、回滚和恢复验证。目前节点和人工备注可记录，但不存在通用的动作/回执对象，也不能把“已建议”与“已生效”混淆。
3. **加强工作区机密保护和备份边界**：数据库和情报结果仍是明文；Hash 能发现普通改动，不能抵抗同时有权限修改数据库和原件的人。应提供明确的本机加密/密钥托管、备份加密、恢复前后完整性清单和销毁策略。电子水印适合追踪报告来源，不能作为原始证据防篡改证明。
4. **完成正式发行链**：当前是 ad-hoc 签名、未 Apple 公证；漏洞私密报告入口和商用授权联系渠道仍待正式仓库配置。发布前需 Developer ID/公证、可验证更新策略、SBOM/许可证清单和依赖公告复扫。

### P1：下一轮实际工作流

1. 统一普通 AI、情报和本地任务的取消、超时、重试、草稿恢复和结构化输出；保留输入范围、模型/提示版本、时间和人工采纳记录。四家官方模型需各自真实账号验收后再标“已验证”。
2. 为 Agent 生成“采集规格/完成清单”：逐项列出权限、版本、成功/缺失/失败、采集时间和目标主机。当前 Agent 是固定有限清单，不是完整磁盘镜像或任意命令终端；eBPF 仅为连接元数据，没有 PCAP 留存、TCP 重组、TLS 解密、进程归属和完整命名空间覆盖。
3. 扩充 WebShell/PE/ELF 覆盖：复杂 AST/污点、运行时解密、内存马驻留证明、脱壳/反编译和动态样本行为仍未实现。动态分析应接入专用可回滚 VM/CAPE；Docker 只作为低风险静态工具隔离层。反调试/沙箱绕过只能记录观察到的迹象，不能声称已绕过。
4. 将规则包版本、来源、作者、日期、许可证、误报说明、测试案例和回滚做成可审计对象；把合成案例评测与真实命中分开显示。补充非命中原文上下文和 Hayabusa/Chainsaw/Falco 有版本导入。
5. 实测 PDF 打印/流转、长报告分页、截图失败、磁盘满、强杀恢复和长期存储压力；目前 HTML/DOCX 有工件验收，PDF 仍依赖系统打印。

### P2：生态与协作

LAN P2P 目前是 IPv4 同网段组播发现、邀请配对、TLS 消息/表情/截图/32 MiB 文件的单机回归；双物理设备、Windows、断线续传、群聊和公网场景没有通过。社区投稿应先限定为带版本/作者/许可证/样例的规则、报告模板和解析配置，导入预览并显式启用，不能给扩展包任意本机命令权限。

## 已修复的本轮问题

- 情报查询在 DNS、IANA RDAP 引导或注册服务重定向准备期间，原先只在最终写回时检查取消/锁定；用户在这段窗口操作可能仍建立新的连接。本版在每个发送边界重新检查事件状态、情报锁和服务配置版本，并用回归测试证明四种撤销场景不会连接。
- 0.10.0 CI 隔离步骤构建 `gaga-analysis:0.7.0`，而实际测试脚本要求 `0.9.0`；已统一为 `0.9.0`，避免干净 CI 因镜像标签不一致而失败。
- 情报快捷入口带入的 IOC 现在绑定事件 ID；切换事件会清除旧快捷入口，避免在新事件预填旧证据。

## 发布判断

可以发布为“macOS 个人蓝队调查开发预览版”，适合本地 HTTP/日志/WebShell 静态/IOC/报告工作流和社区试用；不应发布为“全平台稳定版”“完整取证平台”或“AI 自动研判平台”。公开页面应同时展示能力状态、实测范围、限制、依赖公告和未公证提示，直到 P0 项和实际发行链完成。
