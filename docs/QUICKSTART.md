# 首次完成一次调查

1. 打开客户端，在“事件调查”创建事件。日志、证据、节点和报告都会归入当前事件，开始下一件调查时新建事件。
2. 在“HTTP”把请求和响应分别粘贴到两个框，或导入仓库 fixtures/cases 下的合成案例。消息头和正文之间保留空行。响应缺失时仍可分析请求，但不能确认服务器结果。
3. 在证据结果里核对原文、位置和覆盖缺口。AI 可选：先到“AI 与设置 → 模型连接”保存四家官方服务之一并测试连接；发送前审阅材料。没有 Key 也可以使用本地规则和报告功能。
4. 把有依据的发现加入时间线，填写实际发生时间、负责人和举证说明。同一窗口右侧可选已有报告章节或新建章节，直接粘贴截图并填写图注，也可以先只记时间线。保存节点后继续分析，或选择“保存并打开报告”；不确定的时间和结论保留待复核。
5. 打开顶部独立“报告”，进入报告中心后点击“打开报告编辑器”。编辑基本信息，添加自定义章节及子章节，可按入侵阶段、资产或子事件组织；也可插入五步、入侵阶段、Web 入侵、勒索或容器模板。模板只追加指导性章节，按实际证据填写正文。关联证据节点、截图和负责人。右上角“导出报告”集中提供 HTML、DOCX、打印 / PDF、水印与导出记录。导出前自动保存正文；任务在后台校验原件、编排并写入，可切到其他页面继续调查。任务窗口显示真实校验字节和取消按钮，底部也能返回任务；最终提交时无法取消。成功后核对输出，PDF 使用系统打印另存。
6. 在“AI 与设置 → 数据与维护”创建事件备份，建议恢复到新目录验证后再长期存放。恢复不覆盖当前目录，后台任务默认停用，跨电脑需重新配置模型与系统凭据。此备份不含局域网聊天、配对及电子水印密钥；它们仍需保留原工作区，不能假定跨电脑自动恢复。

HTTP、日志、容器配置和报告操作不要求运行样本。WebShell、PE/ELF 静态解析需要 Docker 与分析镜像；进入“样本分析 → 隔离环境”检查并构建。正式界面不提供测试报文或演示材料入口；请导入自己的授权材料。

0.9.0 WebShell 导入完成后默认打开“分层分析”。左侧选择原文或派生工件，右侧阅读代码/Hex、相关发现和词法关系；展开“摘要与来源”核对 SHA-256 和表达式位置。发现旁的举证按钮仍可填写负责人、时间、截图与报告章节；“AI 复核本层”先打开发送预览，不会自动发出请求。历史材料缺少分层时需用新版镜像重新导入。完整步骤与覆盖范围见 [WebShell 分层分析](WEBSHELL-LAYERS-0.9.0.md)。

敏感客户材料可先点击工具栏锁图标，进入“隐私与外发”锁定新的 AI 请求；本地分析、截图和报告照常使用。自动 AI 默认关闭，只能授权一个事件在启用后新增的观测，历史记录由你从证据页预览后选择发送。解锁不会自动恢复研判。所有联网与导出范围见 [PRIVACY.md](../PRIVACY.md)。

遇到失败先看错误代码与下一步提示，再检查环境或模型连接。反馈问题时附版本、平台、脱敏复现和诊断文件；不要上传完整备份、客户材料、Key 或真实恶意样本。

客户端可恢复已确认写入 SQLite 的报告；未确认草稿在本机 WebView 恢复日志中。存在未保存草稿时备份会提示先完成恢复或保存。日志派生索引不进备份，恢复后可在日志页重建。

## 局域网交流

顶部右侧消息图标打开“局域网协作”。两端都开启协作，一方生成一次性邀请，通过可信渠道交给另一方粘贴配对；同网段可自动发现设备，发现不到时填写对方局域网地址。配对成功后发送文字、表情图片和文件，在输入区用 ⌘V / Ctrl+V 粘贴截图，预览后再发送。附件需对方点击接收；普通文件不会自动打开或执行。

每次重启默认关闭协作，历史保存在原工作区；离线状态约 15 秒内更新。文件上限 32 MiB、图片 8 MiB。完整使用步骤、聊天密钥保管和网络限制见 [局域网协作](C4-lan-0.7.6.md)。

导出快照在后台读取指定事件时捕获，之后的正文/节点编辑留到下次导出。任务不随事件切换而转移，另一个事件的活动任务仍会标明原事件并可取消。一次只导出一份报告，历史只在本次客户端进程保留；退出不自动续传。强制退出可能留下 .gaga-*.partial 临时文件，不要把它当成完成报告。

## 自由编排复杂事件报告

报告保持独立整页编辑。长段说明、报告正文、HTTP 报文和 AI 材料可点击输入区右上角「放大编辑」，在接近整个窗口的空间里编写；点击「完成编辑」或按 Esc 返回。文字与原表单同步，返回后仍需按原流程保存、分析或发送。普通说明至少 180px，长材料至少 260px，报告章节正文至少 320px；普通输入区还可拖动底边增加高度。

新报告目录只有基本信息。点击“新增章节”，填写例如“阶段一：初始入侵”；再点击“新增子章节”，填写“事件 1：Web 服务器”。每节可写独立正文、负责人、开始/完成时间和状态。在“节点与截图”将同一举证关联到一个或多个章节，点击节点粘贴框后用 ⌘V / Ctrl+V 添加截图并填写图注。

上下移动主章节会带上其子章节；子章节可更改所属主章节。最多两级、64 节。删除章节须确认，只删除正文与分组关联，不删除时间线节点、原件或截图；尚未分组的所选节点放在导出附录。五步/入侵阶段模板是追加插入，不会覆盖已写正文。旧五步报告首次读取会迁入对应章节；先前顶层字段保留供兼容，新版导出只使用可见章节正文。

可以先写人工正文再补证据；未关联节点时报告会明确说明举证待补。DOCX 保留标题层级便于继续编辑，HTML/PDF 使用相同章节结构。自动保存确认前仍可点击保存。

## 文件分析进度

分析页默认将空间留给结果；点击标题栏“资料 · N”查找和切换文件，再次点击收起。“摘要与过程”包含文件 SHA-256、指标统计和处理阶段。日志 AI 研判在最小窗口下也可操作；WebShell 按工件选择源码，来源和检查覆盖按需展开。静态分析不运行样本，未命中不代表安全。

日志、WebShell和可执行样本选择文件后创建后台任务，底部“分析任务”可随时展开。运行时可继续切换功能页或事件；任务始终属于选择文件前的事件。日志显示实际字节、行数、解析/跳过和命中，发现预览最多24条；WebShell显示隔离环境检查、工具运行及保存阶段，工具返回后才出现规则结果。

点击“停止分析”后等待停止与清理确认；正在最终保存时不能取消。任务完成后点击“打开结果”，自动回到对应事件和材料页，再继续AI复核、举证或报告编排。失败有任务ID，可在运行日志查询。取消或失败的预览不作为完整证据，原始输入保持不变。重启后未完成任务标记中断，不自动重跑。

## 全局名单与页面截图

“威胁情报 → 黑白名单”新建规则默认全局；切换事件后继续可见。仅本事件用于临时例外，旧事件规则可逐条“设为全局”，不会自动扩大历史例外。规则命中只记录参考依据，不自动封禁或放行；冲突、失效或错误判断仍需人工处理。当前匹配接入页面巡检和流量观测，不能理解为所有分析结果都会被白名单过滤。

在“持续监控 → 资产页面监控”选择资产和历史快照。快照一次显示一份、每页十份。点击“粘贴 / 附入页面截图”后直接 ⌘V / Ctrl+V，填写采集时间和图注，再保存节点；截图与快照 URL、时间、HTML 摘要关联，可进入报告。此处是人工补充截图，不是自动浏览器渲染。静态巡检不执行 JavaScript；HTTP 200 也可能只是跳转占位页，meta refresh 或脚本跳转线索会保留为覆盖缺口，不能据此判定最终页面可信。

## 查询官方情报

先到「AI 与设置 → 情报服务」确认账号授权、保存启用并解锁，再到「威胁情报 → 在线查询」输入允许外发的公网 IP、域名或 Hash。也可在分析结果指标或本地 IOC 复核详情直接带入。结果经「复核并加入事件报告」进入现有节点、截图和报告章节；不会自动上传样本。用法、状态及服务边界见 [0.10.0 情报说明](THREAT-INTELLIGENCE-0.10.0.md)。
