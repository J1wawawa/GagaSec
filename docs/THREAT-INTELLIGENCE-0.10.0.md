# 官方情报查询 · 0.10.0

首批提供微步、域名 RDAP、AbuseIPDB、VirusTotal 既有 Hash 报告的只读适配器。账号授权、接口权限和额度由使用者自己的服务账号决定。验收范围见 [审计记录](AUDIT-0.10.0.md)，公开文档依据见 [API 调研](THREAT-INTELLIGENCE-API-RESEARCH-2026-10-30.md)。

## 开始使用

1. 打开「AI 与设置 → 情报服务」。新工作区默认锁定情报外发，所有服务默认停用。此锁与 AI 外发锁独立，不代替系统防火墙。
2. 选择服务，确认用途、本地保存和报告引用满足账号授权，再保存启用。RDAP 无需 Key；其他 Key 写入系统凭据库。微步还需在官方控制台绑定当前出口 IP 并开通对应接口。
3. 解锁，进入「威胁情报 → 在线查询」，选择服务、调查方向和类型，每行一个指标，每批最多 20 条。可从本地 IOC 复核详情或分析结果的指标列表带入；更改带入内容会清除自动关联的原证据指针。
4. 核对外发对象并勾选确认。即使无结果也可能消耗额度。首批不发送完整 URL、日志或样本字节，不触发扫描、举报、样本下载或清理。
5. 查看结果，选择「复核并加入事件报告」，在现有举证窗口补充现场依据、负责人、发生时间、截图和报告章节。

| 服务 | 首批操作 | 范围 |
| --- | --- | --- |
| 微步 | 入站信誉、出站 C2/失陷线索、IP/域名上下文、已有文件报告 | 按流量方向选接口；场景查询默认仅当前有效，可选包含历史过期情报 |
| RDAP | 当前域名注册信息 | IANA 域名 bootstrap；尚无 IP/ASN RDAP。可能脱敏，不等于历史 WHOIS 或真实控制人 |
| AbuseIPDB | IP 社区举报背景 | 固定最近 30 天，不提交举报；评分不证明本机入侵 |
| VirusTotal | SHA-256 / SHA-1 / MD5 既有文件报告 | 核对 Public API 商业及业务工作流限制；不上传、不重新分析、不下载样本 |

只允许公网 IP、普通域名和文件 Hash。私网、回环、链路本地、保留/文档地址、对应的 IPv4 映射 IPv6，以及已知本地/测试/特殊用途域名标为「未外发」。无法自动辨认所有使用公共域名后缀的内部资产，仍需人工核对。未外发、无结果或零检出均不等于安全。

## 状态、缓存和任务

- 请求状态与服务结论分别保存，人工 IOC 分类不被覆盖。区分排队、运行、完成、未外发、失败、取消、中断；结果另分有情报、无数据、部分结果、厂商处理中、权限/账号/出口 IP 问题、限频/额度和到期。
- HTTP 200 仍要判断微步业务码。厂商处理中只表示本次查询完成，报告尚未完成；不自动轮询或重新提交。
- 全工作区最多 40 个排队/运行任务。进程使用单个网络通道，保守间隔一般 2 秒、VT 16 秒；这是客户端节流，不是账号额度或余额。
- 同事件、服务配置版本、操作、规范化指标及历史范围的一小时成功/无数据缓存可复用，保留原取得时间与来源任务。跨事件/配置不复用。可选择跳过缓存，可能再次计费。
- 一次查询不自动重试。鉴权、权限、出口 IP、额度拒绝或传输失败停止本批后续查询。微步按记录扣费，空结果、处理中也可能计数，不能把 HTTP 请求数当官方账单。
- 列表只取最新 200 条摘要，不带大响应；详情单独读取，单响应最多 2 MiB。界面 JSON 预览最多 64,000 字符，举证保存完整有界结果。数据库历史不自动清理，需继续备份和维护。
- 任务固定所属事件，切页不改归属。取消和锁定阻止后续操作，但不能撤回已发送数据；晚到响应不覆盖取消状态。重启将旧未完成任务标为中断，不自动联网恢复。

尚无厂商余额查询、真实扣费明细、事件级授权策略、统一全功能断网开关或受控代理适配。不要将这些设计待办描述为现有能力。

## 举证与安全边界

JSON 经格式/大小检查和凭据字段脱敏；结果 SHA-256 针对脱敏后 `serde_json` 序列化的对象，**不是 HTTP 原始字节摘要**。归档先校验摘要，再保存 `gaga-enrichment/1` JSON 原件。重复归档同一任务复用已有证据。既有节点、截图、自由章节、时间胶囊、HTML/DOCX/系统打印 PDF 继续使用。

取得时间、厂商分析/观察时间与现场发生时间不同。响应实际含有哪些时间就保留哪些，不补造字段。报告保留查询范围、来源、摘要和复核依据；外部恶意标签不能单独证明本机失陷。服务保存/引用授权不自动包含对外再分发许可。

Key 由宿主后端读取，不进前端配置返回值、数据库、AI Prompt、容器、IOC 导出或诊断；系统授权读取最多等待 30 秒。凭据按工作区路径与厂商隔离，迁移路径后需重新保存。恢复备份清除情报服务配置。

使用固定官方 HTTPS 接口，DNS 检查后绑定地址，拒绝本地/保留目标；不使用代理转发以避免绕过地址校验。携带 Key 的服务拒绝重定向，RDAP 无 Key 重定向最多 4 次且每跳重验。单请求 25 秒，网络阶段总预算 40 秒，响应上限 2 MiB。企业环境要求代理时可能连接失败，当前不绕过证书检查。

远程响应按不可信文本展示，不执行脚本、不加载远程图片、不自动打开返回链接。HTTP 鉴权/配额错误不保存正文；运行日志仅记安全错误描述，不记指标和请求参数。原始结果在本地明文保存，继承现有证据库保护边界，不是防管理员修改的存储。

ThreatFox/URLhaus、GreyNoise、urlscan、IP/ASN RDAP、额外上下文关联与单独授权的主动提交仍在后续批次。
