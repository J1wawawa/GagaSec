# 嘎嘎安全助手 0.6.4 体验优化与 DeepSeek 实测

J4team · 2026-10-28 · Apple Silicon macOS 开发预览版。

本轮针对导航拥挤、重复标题和分析区被输入区挤压的问题改版，并使用原先保存在系统凭据服务中的 DeepSeek Key，通过真实客户端控件执行官方 API 请求。使用独立事件和明确的合成材料；用户原工作区和密钥保留。

## 体验调整

- 保留总览与八个任务入口。日志、HTTP、告警等单一入口去掉重复二级导航；复合分组继续显示相关子工具。
- 分析页只保留一行标题与主要命令，格式、范围和限制可通过「分析说明」展开，并支持 Esc 关闭。
- HTTP / 告警录入与归档结果分别使用完整工作区，可通过「新增报文对 / 新增告警」和「返回分析结果」切换；草稿保留。告警归档成功后收起录入区。
- AI 复核与记录调查结论固定在证据标题右侧；当前文件名称过长时省略显示并可悬停查看，统计摘要紧凑排列。
- 分析过程默认展示状态、模型和耗时；完整分析 ID 及实际步骤在展开后查看，运行中自动展开。分析引擎信息移入文件信息页签。
- 平台页与动态分析页统一较紧凑的标题间距；常用按钮使用短暂颜色 / 按压反馈，尊重减少动态效果设置。

共用样式集中在 `src/analysis-workspace.css`，清理 31 条被替代的分析密度规则；原始证据、事件隔离和人工复核边界继续保留。

## 真实 DeepSeek 流程

本轮使用 **DeepSeek Flash**；从已有工作区复制配置元数据到新验收库，密钥由系统凭据服务读取，不写入脚本或命令参数。专用原生验收模式禁用本机模型模拟。

| 实际操作 | 结果 |
|---|---|
| 设置页面点击连接验证 | 官方返回 GAGA_OK，12.855 秒 |
| 粘贴请求与响应 → 联合分析 → 预览材料 → AI 复核 | 官方结构化研判保存并展示，5.182 秒 |
| 粘贴合成 NDR 告警 → 本地检查 → AI 复核 | 官方结构化研判保存并展示，3.841 秒 |
| 分析内置合成日志 → 行为时间线 → AI 复核 | 官方结构化研判保存并展示，7.071 秒 |
| HTTP 对话追问 | 官方回复显示并持久保存 |
| 关闭并重新启动客户端 | 三类结构化结论与 HTTP 追问均能正常打开，未重复调用官方接口 |

实际发送 **5 次**请求：连接一次、研判三次、追问一次。上述耗时仅代表本机本次请求，不构成性能或模型准确率保证。语法解析、过程保存、界面显示与重开检查通过，不等于模型研判可替代人工举证。

## 本轮验收

- 原生导航与交互：113 项通过，含最小窗口明暗主题、直接入口、工具查找、草稿保留、单行标题、按需说明与键盘关闭。
- HTTP：20 项原生检查、7 项持久化检查通过，覆盖错误提示、原始输入保留与重试。
- 既有大日志 / 容器工作区：16 项原生检查通过，核对 1 GiB 日志尾部举证、AI 材料、WebShell 对照和采集缺失项；本轮没有重新执行大日志扫描或容器采集。
- DeepSeek：21 项原生流程检查；重新启动后的 6 项检查通过，SQLite 完整性与源配置未变也已核对。
- 浏览器补充：导航 127 项、调查视图 55 项、平台 44 项检查通过，平台覆盖 60 个视图组合。三尺寸：1320×860、1100×760、960×660，明暗主题。
- TypeScript / Vite、Tauri .app 打包、Prettier 与 cargo fmt 通过。

首次原生导航脚本在 120 秒等待预算内未写出结果；将预算调至 240 秒后以单实例复跑，通过上述 113 项检查。首次超时原因未确定，不将它当作已经定位并修复的产品缺陷。原生 UI 流程继续串行运行。

界面输入与快捷键为 DOM 事件注入，未作为物理系统键盘操作验收；附图明确为浏览器预览。Windows / CAPE、其他厂商官方接口、系统打印 PDF、多实例可靠性及先前未实现能力，继续以 0.6.2 验收报告列出的边界为准。
