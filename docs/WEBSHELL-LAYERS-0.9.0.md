# WebShell 分层静态分析 · 0.9.0

本轮是[调研实施清单](RESEARCH-IMPLEMENTATION-2026-10-30.md)中的首批功能。目标是帮助调查人员看清多层常量编码、来源和覆盖缺口，并把核对后的发现纳入事件报告，不承诺复杂 WebShell 全覆盖。

## 使用

1. 启动 Docker，在“样本分析 → 隔离环境”构建 `gaga-analysis:0.9.0`。仅使用旧镜像无法获得新版结果。
2. 进入 WebShell 页导入授权文件；后台任务归档原件并在禁网容器解析，不执行源码。完成后点击“打开结果”。
3. “分层分析”左侧列出 L000 原文及派生工件，右侧展示代码或有界 Hex。选择一个工件查看关联发现、输入关系及覆盖情况。
4. “摘要与来源”保留输入/输出 SHA-256、父层、表达式所属层、行号和字节范围。复制变换记录可获取这些元数据，复制代码只复制当前有界预览。
5. 发现旁举证可填写时间、负责人、说明、粘贴截图并选择报告章节。按层 AI 按钮先显示可编辑材料，遵守现有外发锁与四家官方服务限制；未点击发送不调用模型。普通整份证据预览会遮盖常见敏感字段，按层材料保留所选代码预览，需在发送框中检查并删减敏感内容，不能假定已自动脱敏。
6. 顶部独立“报告”可追加 Web 入侵、勒索或容器模板；仍可自定义主/子章节，关联已有节点。HTML/DOCX 带派生层位置和摘要，原件继续按完整 SHA-256 校验。

旧证据没有 `webshell` 字段时继续可读，分层页提示重新导入，不覆盖旧分析。派生预览与摘要随证据重启保留；完整派生文件没有落库或下载入口，需要从原件复现。

## 已实现的静态操作

有界 lexer 跳过行/块注释及字符串中的伪调用。固定字符串、`.`/`+` 拼接、`chr`、PHP 固定变量和函数别名可参与常量求值；PHP 变量区分大小写。支持 `base64_decode`/`atob`、`gzinflate`、`gzuncompress`、`gzdecode`、`str_rot13`、`strrev`、`hex2bin`、`urldecode`、`rawurldecode`。未知调用、插值、外部输入与未知重新赋值不进行猜测。

敏感调用覆盖动态执行、系统命令、类/程序集加载、反序列化入口、文件写入/上传与间接回调；保留 Java Runtime、ProcessBuilder 和 .NET Process/Assembly 线索。这些可能出现在正常代码和不可达分支中。请求输入到敏感调用的关系仅为同语句/先前赋值的词法线索，不证明输入实际流入、分支可达或攻击成功。

发现 `CAFEBABE` 时读取有界 Java 常量池，提取部分 Servlet、Runtime、ClassLoader 等字符串；不加载类、不运行 JVM，也不是反编译或完整字节码认证。发现 `ACED0005` 时仅识别 Java 序列化头，不反序列化。

## 工件来源与预算

`parentId` 表示变换输入的父工件；`sourceLayerId` 表示调用表达式所在层。两者可以不同：原文中嵌套的 Base64 → inflate，第二步读取 Base64 产生的字节，但第二步表达式仍位于原文。字节范围为半开区间，不能当作派生输出到原文的一一映射。

| 范围 | 上限 |
| --- | --- |
| 可导入原文件 | 8 MiB；完整归档和 Hash |
| 原件深度分析 | 前 1 MiB |
| 派生工件 | 深度 8、总数 48（含原层） |
| 字节预算 | 单层 1 MiB、累计 4 MiB |
| 解压展开 | 另受输入大小放大比限制，超出拒绝 |
| 解析预算 | 120000 tokens、4096 次变换尝试、3 秒软处理预算 |
| 发现 / 关系 | 最多 400 / 100 项 |
| 保存预览 | 每层 6000 字；二进制前 256 字节 Hex |
| Java 常量池 | 最多 10000 entries，保留 500 条 UTF8、每条 1000 字；详情前 80 条 |

达到限制、损坏压缩、未知格式和未解析类池会说明缺口；“没有发现”不等于“没有 WebShell”。软预算不是硬实时保证，容器还受 CPU、内存、进程数和外层命令超时限制。工具报告返回并校验后才展示层结构，没有逐层实时推送。
