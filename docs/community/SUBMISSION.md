# 社区投稿模板

## 基本信息

- 类型：功能 / 规则 / 日志适配 / 案例文章 / 报告模板 / 体验 / 代码 / 文档。
- 标题：一句话说明要解决什么问题。
- 作者署名方式：姓名、昵称或匿名；不要填私人联系信息。
- 适用版本与环境：客户端版本、系统架构、Docker/目标内核等相关信息。

## 正文

1. 场景：授权范围、输入材料类型、实际工作目标。
2. 当前问题：现在如何操作，哪里费时、容易遗漏或判断错误。
3. 内容或方案：具体逻辑、步骤、文章或模板，区分观察事实与推测。
4. 举证：合成或已授权脱敏样例，保留必要结构与预期定位。
5. 正常反例与限制：哪些情况不应命中，哪些环境尚未验证。
6. 验收：输入什么、执行什么、期望出现什么，如何验证未误改其他事件。
7. 来源与许可：原创部分、引用来源、第三方素材的授权说明。

请只附 Hash 或公开报告链接，不直接附真实恶意样本。不要附完整工作区、客户日志、任务 ZIP、密钥或未公开漏洞信息。
